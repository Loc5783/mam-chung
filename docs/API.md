# API giai đoạn 0

GET /api/health: 200 khi MongoDB đã kết nối, 503 khi chưa sẵn sàng.
GET /api/docs: Swagger cho endpoint health.
Các endpoint nghiệp vụ ở mục 14 sẽ được thêm theo từng giai đoạn, chưa tồn tại ở bản này.
